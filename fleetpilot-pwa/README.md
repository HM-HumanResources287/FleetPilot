# 🚀 FleetPilot - PWA

تطبيق إدارة مالية متكامل للسائقين، يعمل كـ PWA على الهواتف والحواسيب.

---

## ✨ المميزات

- ✅ تسجيل الشفتات اليومية مع تفاصيل الإيرادات والمصاريف
- ✅ إدارة الديون والتوفير
- ✅ دعم البصمة و PIN للأمان
- ✅ واجهة عربية وإنجليزية (متعددة اللغات)
- ✅ تقارير وتحليلات مالية
- ✅ وضع الداكن والفاتح
- ✅ يعمل بدون إنترنت (Service Worker)
- ✅ قابل للتثبيت على الهاتف كـ PWA

---

## 🛠️ التقنيات المستخدمة

- HTML5 / CSS3 / JavaScript
- Firebase (Authentication + Firestore)
- PWA (Service Worker + Manifest)
- Chart.js (الرسوم البيانية)
- html2pdf (تصدير التقارير)
